# Mood Journey PHQ-9

เว็บแอปแบบสตอรี่ IG สำหรับทำแบบประเมิน PHQ-9 พร้อมตัวการ์ตูนและการ์ดผลลัพธ์ที่บันทึกเป็นรูปได้

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ static server ใดก็ได้

```bash
node server.mjs
```

แล้วเปิด `http://127.0.0.1:4173`

## Deploy บน Vercel

โปรเจกต์นี้เป็น static site ไม่ต้อง build

1. Push โฟลเดอร์นี้ขึ้น GitHub
2. เข้า Vercel แล้วเลือก Import Git Repository
3. Framework Preset: Other
4. Build Command: เว้นว่าง
5. Output Directory: `.`

## หมายเหตุด้านสุขภาพ

PHQ-9 เป็นแบบคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์ หากคะแนนสูงหรือมีความคิดทำร้ายตัวเอง ควรติดต่อผู้เชี่ยวชาญ คนใกล้ตัว หรือบริการฉุกเฉินในพื้นที่
